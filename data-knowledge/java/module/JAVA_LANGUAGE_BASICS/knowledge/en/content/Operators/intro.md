# Expressions and Operators

Operators are not merely shorthand symbols. Java applies promotion, grouping, evaluation-order, and short-circuit rules around them.

Common groups include:

- arithmetic: `+`, `-`, `*`, `/`, `%`;
- unary: `+`, `-`, `++`, `--`, `!`, `~`;
- comparison: `<`, `<=`, `>`, `>=`, `==`, `!=`;
- logical: `&&`, `||`, `!`;
- bitwise/shift: `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`;
- assignment: `=`, `+=`, `-=`, `*=`, ...;
- conditional: `condition ? a : b`.
