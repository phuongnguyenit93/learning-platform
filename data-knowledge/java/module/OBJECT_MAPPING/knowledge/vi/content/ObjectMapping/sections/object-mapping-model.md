```text
Source Model
     ↓
mapping rules
     ↓
conversion / transformation
     ↓
Target Model
```

Mapping rule có thể là:

- copy trực tiếp field;
- rename field;
- convert type;
- map nested object;
- map collection;
- derive một field từ nhiều source;
- bỏ qua field không thuộc target contract.
